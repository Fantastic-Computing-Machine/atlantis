# Mermaid Examples

A few ready-to-use Mermaid snippets you can copy into Atlantis:

- `architecture.mmd` – service boxes with data flow and dependencies.
- `sequence.mmd` – request/response path through client → API → services → DB/cache.
- `flowchart.mmd` – decision flow for feature rollout with approvals and metrics.

Use these as a starting point for new diagrams or to validate imports.
