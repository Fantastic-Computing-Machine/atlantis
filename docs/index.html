Quick start

Run it. Make it yours.

The Docker Hub image gives you one container, a persistent data volume, and a workspace at localhost:3000.

Terminal 
docker run -d -p 3000:3000 \
  -v $(pwd)/data:/app/data \
  --name atlantis \
  strikead/atlantis:latest

Prefer a local checkout? Read the setup guide ↗.
